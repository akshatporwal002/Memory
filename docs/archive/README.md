# Documentation archive

Archived 5 October 2026 while reviewing main `381c917`. Original content and dated evidence are retained. **Newer documentation overrides conflicting older directions.** Start with [current status](../CURRENT-STATUS.md), [active requirements](../README.md) and [remaining work](../BACKLOG.md).

“Completed” identifies a delivered stage, not complete product/release acceptance. Outstanding hardware, live-service and accessibility checks are carried into the backlog. Mixed documents were archived after extracting still-applicable work. The two latest October 4 specifications remain active.

## Conflict decisions

- October 2 Library and Activity directions supersede the older Gallery/List and Bars/Line preferences. Those controls are not unfinished work to restore.
- October 4 consolidated requirements supersede the voice specification’s deferrals of Google BYOK, cloud speech and combined audio, while retaining its payment rules.
- October 4 paid voice rules supersede the early free/local and one-time BYOK pricing ideas.
- Later follow-ups in the October 3 retention report supersede fixed-axis and equal-review-step proposals: calendar time, one-month initial view and dynamic visible-window scaling are the latest direction.
- Native Apple build/review reports supersede the September Windows-only “Apple checks have never run” status; untested device/live-service checks remain open.
- SQLite/cloud/account implementation supersedes the original JSON-only/no-sync architecture. Hosted cloud activation still has separate gates.
- Corrected import findings remain historical regression evidence; they are not carried forward as unresolved bugs.
