Protobuf defines language bridge requests and some stored structures; it is explicitly not a public stable API. Engram should adopt separation of responsibilities, not this desktop presentation stack.

## Data and scheduling semantics

Observed in [card types/queues](https://github.com/ankitects/anki/blob/39e4b0b48c5bb22e9c22ad87c64ff14e6a24dc20/rslib/src/card/mod.rs): `type` and `queue` are separate. Types are new, learning, review and relearning. Negative queues represent suspended, scheduler-buried and user-buried cards. `due` is an ordering value for new cards, UNIX seconds for intraday learning/preview repeats, and collection-relative day counts for review/interday learning. `odid` and `odue` preserve filtered-deck origin. Preserve raw source fields before converting them.

[Timing](https://github.com/ankitects/anki/blob/39e4b0b48c5bb22e9c22ad87c64ff14e6a24dc20/rslib/src/scheduler/timing.rs) selects among v1, legacy v2 and creation-offset-aware timing using rollover and creation offset. Its tests exercise days before rollover and differing offsets. A review due number cannot be interpreted correctly without collection creation/date policy. Engram should preserve collection epoch, source scheduler version, rollover and offsets in import provenance, and store its own explicit due representation. Calendar/day-boundary changes require tests around travel and daylight saving.

[Card-data serialization](https://github.com/ankitects/anki/blob/39e4b0b48c5bb22e9c22ad87c64ff14e6a24dc20/rslib/src/storage/card/data.rs) stores optional FSRS stability `s`, difficulty `d`, desired retention `dr`, `decay`, last-review time `lrt`, prior new position `pos` and custom-data `cd`. Preserve unknown/raw data alongside typed known fields. Engram should fail closed on unsupported scheduler-state versions, not interpret absent state as a new mature card.

[Revlog](https://github.com/ankitects/anki/blob/39e4b0b48c5bb22e9c22ad87c64ff14e6a24dc20/rslib/src/revlog/mod.rs) uses millisecond identifiers; interval and previous interval are positive days or negative seconds. Rating zero means manual rescheduling; old v1 learning button 3 meant Easy. `factor` represents SM-2 ease or normalized FSRS difficulty depending on state. Kinds include learning/review/relearning/filtered/manual/rescheduled. Import raw evidence with origin IDs and source kind; do not coerce every row into a normal 1–4 Engram recall event or invent missing history.

Generation tests explicitly cover Unicode, nested clozes, hints and comma-separated ordinals such as `{{c1,2::shared}}`. For ordinary `{{cN::text::hint}}`, all markers with the same N are hidden together; unique numbers produce siblings. Stable source clamps generated ordinals to its supported range. Engram may initially author a simpler syntax, but detection must flag unsupported imported nesting or comma syntax before import; a regex that silently leaks answers is insufficient.

## Package interoperability contract

The manual distinguishes [export modes](https://docs.ankiweb.net/exporting.html) and [packaged-deck import](https://docs.ankiweb.net/importing/packaged-decks.html). Deck packages merge; Anki collection packages replace collection content. Engram's approved workflow deliberately requires explicit new-library or safe merge with backup instead of silent replacement. Old `collection.apkg` names can carry collection semantics. Content and metadata, not just extension, must select the parser.

Observed in [package metadata](https://github.com/ankitects/anki/blob/39e4b0b48c5bb22e9c22ad87c64ff14e6a24dc20/rslib/src/import_export/package/meta.rs) and [media code](https://github.com/ankitects/anki/blob/39e4b0b48c5bb22e9c22ad87c64ff14e6a24dc20/rslib/src/import_export/package/media.rs):

| Variant observed in 26.08.1 | Collection member | Schema compatibility | Media manifest/payload |
| --- | --- | --- | --- |
| Legacy1 | `collection.anki2` | 11 | JSON numbered-entry-to-name mapping; legacy data copy |
| Legacy2 | `collection.anki21` | 11 | Same legacy manifest representation |
| Latest | `collection.anki21b` | 18 | Protobuf metadata/media entries, zstd compressed collection/media; media entries include size/checksum |

Presence of `meta` selects an explicit version; absent metadata falls back based on legacy member names. Unknown versions produce TooNew. Current source checks safe normalized filenames and manifest references. Engram needs its own preflight archive entry-count, expanded-size, compression-ratio and path checks, checksum validation, duplicate-name policy and isolated temporary extraction before any active-library mutation. Missing ordinary media should be counted and shown, not silently discarded. Never execute imported scripts with app privileges.

[Note import](https://github.com/ankitects/anki/blob/39e4b0b48c5bb22e9c22ad87c64ff14e6a24dc20/rslib/src/import_export/package/apkg/import/notes.rs) matches GUIDs and applies update policies, checks note-type conflicts and maintains ID/field/template remapping. Embedded tests include unique GUID with colliding numeric ID, newer-target note, matching GUID with different ID, incompatible note type and repeated merged imports. [Card import](https://github.com/ankitects/anki/blob/39e4b0b48c5bb22e9c22ad87c64ff14e6a24dc20/rslib/src/import_export/package/apkg/import/cards.rs) detects existing `(note, ordinal)` cards, shifts collection-relative dates, maps decks/templates, uniquifies IDs and remaps associated review logs. It explicitly does not update every existing card schedule. Engram should surface keep/update/skip choices, namespace source IDs and preserve its own local edits under a documented policy.

[APKG export](https://github.com/ankitects/anki/blob/39e4b0b48c5bb22e9c22ad87c64ff14e6a24dc20/rslib/src/import_export/package/apkg/export.rs) gathers into a temporary collection/package and atomically renames the result. [Gathering](https://github.com/ankitects/anki/blob/39e4b0b48c5bb22e9c22ad87c64ff14e6a24dc20/rslib/src/import_export/gather.rs) distinguishes scheduling transfer from sharing; the latter resets schedules and removes system tags such as marked/leech. It gathers media from notes and note types. Selected-card search can bring the note's related cards into export; document actual export granularity. Complete native backups must preserve all originals and media, independent of this compatibility export.

### Recommended acceptance boundary; no support claim yet

Target **Anki Desktop 26.08.1** initially, covering its legacy-compatible and modern APKG/COLPKG outputs. This is the inspected validation target, not a claim that any Engram implementation already supports them. Do not advertise “all Anki versions.” If only legacy variants have passed fixtures, name precisely those variants and show a preflight unsupported result for modern ones; modern support remains required unfinished work rather than silently removed scope. Older release claims need separately generated, version-labelled fixtures.

Use independent parsing/serialization at the Anki adapter boundary. Produce a validated intermediate collection plus compatibility findings; mutation belongs to application use cases. Store source IDs, GUIDs, original fields/templates/CSS, raw scheduler rows and collection provenance. Only offer exact scheduling continuation for mappings demonstrated by tests. Otherwise offer clearly labelled content-only/reinitialization choices with explicit consent and preserve original evidence in native backups. Never silently reset mature cards.

## Licensing and provenance

The pinned [root LICENSE](https://github.com/ankitects/anki/blob/39e4b0b48c5bb22e9c22ad87c64ff14e6a24dc20/LICENSE), Cargo metadata and inspected Rust/Python file headers identify AGPL-3.0-or-later, with listed exceptions. Separately, upstream [fsrs-rs LICENSE](https://raw.githubusercontent.com/open-spaced-repetition/fsrs-rs/main/LICENSE) is BSD-3-Clause and [swift-fsrs LICENSE](https://raw.githubusercontent.com/open-spaced-repetition/swift-fsrs/main/LICENSE) is MIT. The [swift-fsrs README](https://github.com/open-spaced-repetition/swift-fsrs) currently distinguishes 19-parameter FSRS-5 defaults from explicit 21-parameter FSRS-6; choose deliberately, then verify available Swift compiler/Apple targets and cross-implementation vectors. No Apple build was run for this research.
